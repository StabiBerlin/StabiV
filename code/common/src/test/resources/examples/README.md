# StabiV Examples

This directory contains 3 example datasets and configurations that can be used for experimentation and as templates for new validation projects.

- `simple` - a minimal example with basic validation rules
- `spk-berlin` - a detailed example with validation rules based on requirements defined by SPK-Berlin
- `stress` - scripts to generate large datasets for stress testing

For detailed information about StabiV, please read the user guide.
